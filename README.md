# ENIGMA I 分解シミュレーター

ドイツ陸軍用エニグマI型を、実際のローター配線で計算して動かす3Dシミュレーターです。1打鍵ごとに、キー → プラグボード → 3枚のローター → 反転ローター → ランプの電流経路を3Dと模式図で表示します。

**デモ：** https://tokyobranding.org/enigma-simulator/

## できること

- **暗号メッセージの送受信**：文章（日本語OK）を暗号にして「暗号文入りURL」と「復号キー」を作成。受け取った人はURLを開いてキーを入れると復号できます。
- **3Dで仕組みを見る**：ローター分解、X線（本体を透かす）、ローターだけ表示、電流経路の表示切替、5つの視点。
- **計器パネル**：ローター位置、打鍵数と周期（16,900）、配線の模式図、その位置の換字表（13組の対）。
- **鍵の設定**：ローターI〜Vの選択と順序、リング、反転ローター（UKW-B/C）、プラグボード。
- **自動ツアー**：放置すると自動で操作を実演し、触れると操作が切り替わります。

## 仕組み

- 計算モデル（`src/model.js`）は純関数で、3D・パネル・模式図はすべてこのモデルを参照します。
- 中ローターのダブルステップを含むステップ機構を再現しています。
- エニグマはA〜Zしか扱えないため、文章はUTF-8のバイト列をA〜Pの2文字に置き換えてから暗号化します。

## 検算

```
node test/model.test.js
```

既知の検証値（I-II-III・AAA・AAAAA → BDZGO、リングBBB → EWTYX）、ダブルステップ（ADU → ADV → AEW → BFX）、周期16,900、反転性と自己換字なしを確認します。

## ビルド

`src/page.html` と `src/model.js` を1枚の `index.html` にまとめます。

```
python3 build.py
```

## 注意

エニグマは第二次世界大戦中に解読された暗号方式です。学習や遊びのためのもので、本当に秘密にしたい内容には使わないでください。
